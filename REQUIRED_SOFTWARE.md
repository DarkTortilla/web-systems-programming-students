# Required Software

Install the following tools before beginning the course:

## Required

- Node.js, current LTS release (includes npm).
- Git.
- Visual Studio Code or another source-code editor.
- A modern web browser with developer tools, such as Chrome, Edge, or Firefox.

## Recommended

- Postman or Insomnia for testing HTTP APIs.
- A GitHub account for remote repositories and collaboration.

## Verification

Run these commands in a terminal to verify the main installations:

```sh
node --version
npm --version
git --version
```
