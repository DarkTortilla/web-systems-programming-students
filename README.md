# Programación de Sistemas Web

## Descripción general

Curso teórico-práctico dirigido a estudiantes de 5.º semestre de Ingeniería en
Sistemas Computacionales, orientado a la comprensión y aplicación de los
fundamentos del desarrollo web, utilizando HTML5, CSS3 y JavaScript como
herramientas clave para la construcción de aplicaciones del lado del cliente
(front-end). Asimismo, se introducen los conceptos fundamentales del desarrollo
del lado del servidor (back-end), incluyendo la interacción con bases de datos,
para construir sitios web funcionales orientados a la gestión de información.

Esta asignatura se apoya en conocimientos previos de Programación III y Bases de
Datos, y proporciona una base esencial para materias complementarias como Redes
de Computadoras II, así como para asignaturas posteriores como Seminario de
Sistemas Computacionales II, Tecnología Web y Programación de Dispositivos
Móviles.

## Objetivo general

Al finalizar la materia, el estudiante construirá aplicaciones web bajo la
arquitectura cliente-servidor mediante el uso de herramientas de software que
satisfagan las necesidades de información de un sitio web, en combinación con
el uso de bases de datos y aplicando creatividad, proactividad y calidad.

## Objetivos particulares

Al término del curso, el estudiante debe estar en capacidad de:

- Construir programas del lado del cliente con HTML, CSS y JavaScript.
- Elaborar programas del lado del servidor y manejar bases de datos.
- Desarrollar aplicaciones web con arquitectura cliente-servidor.
- Distinguir las aplicaciones web desde el punto de vista cliente-servidor para
  emplearlas en el desarrollo de sistemas web.
- Implementar páginas web utilizando HTML5, CSS3 y JavaScript.
- Diseñar y desarrollar aplicaciones del lado del cliente (front-end).
- Diseñar y desarrollar aplicaciones del lado del servidor (back-end).
- Utilizar herramientas de software para crear aplicaciones web con bases de
  datos.

  - [ ] 1.1. Evolución web.
  - [ ] 1.2. Conceptos de front-end y back-end.
  - [ ] 1.3. Editores web.
- [ ] 2. Lenguaje de marcas HTML5.
  - [ ] 2.1. Estructura básica y etiquetas semánticas.
  - [ ] 2.2. Etiquetas y atributos.
    - [ ] 2.2.1. Encabezados, párrafos y listas.
    - [ ] 2.2.2. Tablas y formularios.
    - [ ] 2.2.3. Manejo de identificadores y clases para etiquetas.
    - [ ] 2.2.4. Uso de `div` y `span`.
- [ ] 3. Hojas de estilo CSS en línea, internas y externas.
  - [ ] 3.1. Propiedades de estilo y selectores.
  - [ ] 3.2. Aplicación de diseño a la estructura semántica de una página web:
    maquetación, tablas y formularios.

  - [ ] 3.4. Flexbox y CSS Grid.
  - [ ] 3.5. Manejo de frameworks de diseño: Bootstrap y Tailwind CSS.
- [ ] 4. Introducción a los gestores de contenidos (CMS).

- [ ] 1. Arquitectura de las aplicaciones web.
- [ ] 2. Lenguajes de programación del lado del cliente.
- [ ] 3. Lenguajes de programación del lado del servidor.
- [ ] 4. Ambientes para el desarrollo de aplicaciones web.
- [ ] 5. Metodologías para el desarrollo de aplicaciones web.
- [ ] 6. Seguridad en aplicaciones web.

- [ ] 2. Herramientas y entornos para el desarrollo back-end.
- [ ] 3. Operadores, estructuras de control y manejo de errores.
- [ ] 4. Arreglos y funciones.
- [ ] 5. Procesamiento de formularios y métodos HTTP (`GET`, `POST`, etc.).
- [ ] 6. Gestión de sesiones y cookies.
- [ ] 7. Manejo de archivos en el servidor.

- [ ] 12. Despliegue de aplicaciones.
- [ ] 13. Introducción al desarrollo de servicios RESTful (API REST).
