# Web Systems Programming

Student repository for the Web Systems Programming course.

## Course purpose

Develop the skills required to design, implement, test, and publish web
applications using JavaScript, Node.js, and Express.

## Course content

1. Web fundamentals: HTTP, URLs, clients, servers, and browsers.
2. HTML, CSS, and client-side JavaScript fundamentals.
3. Node.js, npm, modules, and asynchronous programming.
4. Web servers and routing with Express.
5. REST APIs, middleware, validation, and error handling.
6. Data persistence and database integration.
7. Authentication and basic web security.
8. Automated testing, version control, and deployment.

## Repository structure

- `classes/`: examples and exercises developed during class.
- `assignments/`: instructions and starter files for assignments.
- `documents/`: course references and supporting documents.
