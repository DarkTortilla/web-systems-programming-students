# Evaluation

## Initial evaluation scheme

| Component | Weight |
| --- | ---: |
| Assignments and practical exercises | 35% |
| Web development projects | 35% |
| Exams | 20% |
| Participation and class activities | 10% |
| **Total** | **100%** |

## General criteria

- Correctness and fulfillment of requirements.
- Code quality, organization, and readability.
- Appropriate use of Git and documented development progress.
- Testing and error handling.
- Timely submission and presentation of the work.

The professor will publish the detailed rubric and submission rules for each
activity before its due date.
